A tiny fun API for jokes, quotes, facts, roasts, and motivation.

Toaster API is a free, open-source, static JSON API that can be hosted on GitHub, served through jsDelivr, and used in websites, Android apps, docs, demos, and fun projects.

🎲 Random Client

Use the included JavaScript helper to pick random content client-side.

fetch("https://cdn.jsdelivr.net/gh/TutorialsAndroid/toaster-api@main/api/v1/jokes.json")
  .then(res => res.json())
  .then(data => console.log(data.items));
